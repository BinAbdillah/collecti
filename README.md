# Pueny Collections 🧕

> *"Anggun, Modest dan Stylish dalam Fitrah"*

Website e-commerce untuk penjualan pakaian muslimah wanita.

## Produk
- Gamis
- Kebaya Muslimah
- Kulot
- Khimar
- *(More coming soon)*

## Segment
- Affordable
- By Request (custom order)

## Fitur Utama
| Fitur | Deskripsi |
|-------|-----------|
| Mix & Match Builder | Kombinasi atasan + bawahan + khimar |
| Size Finder | Rekomendasi ukuran berdasarkan tinggi/berat |
| Style My Look | Quiz personalisasi rekomendasi outfit |
| By Request | Custom bahan, warna, ukuran |

## Koleksi Khusus
- Idul Fitri

## Cara Menjalankan
1. Buka folder project
2. Buka `index.html` di browser
3. Untuk admin: buka `admin/index.html`
